# ኔት

Personal site. Edit the `site` object at the top of `site.js` to change the words. Leave a field as `""` or `[]` to hide it.

## Add it to GitHub

1. On GitHub, create a new **public** repository.
2. Choose **uploading an existing file** and drag in everything in this folder, including the hidden `.nojekyll` file.
3. Commit the upload.
4. Open **Settings → Pages**. Set the source to the `main` branch and the `/` (root) folder, then save.
5. After a minute, the site is at `https://<your-username>.github.io/<repository-name>/`.

If the repository is named exactly `<your-username>.github.io`, the address is `https://<your-username>.github.io/` instead.
